# Сервис записи к врачам

Учебный проект по дисциплине «Методы оптимизации в разработке программных решений». Выполняется одним разработчиком. Для реализации выбран Laravel.

Сервис предназначен для одной клиники. Пациент сможет зарегистрироваться, выбрать врача и свободное время, записаться на приём и отменить свою запись. Администратор сможет подготавливать расписание. После регистрации, записи и отмены пациенту отправляется email-уведомление.
