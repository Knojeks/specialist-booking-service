# Оптимизация конвейера CI

## Цель

Измерить исходное время CI и проверить влияние трёх последовательных оптимизаций.

## Исходные данные

Проект Laravel, GitHub Actions, PR #15.
Исходный конвейер выполняет все этапы последовательно,
без явно настроенного кеширования зависимостей и Docker-слоёв.

Проведено пять успешных запусков одной версии конвейера:
GitHub Actions CI #4, попытки 1–5.
Запуск с намеренной ошибкой в измерения не включён.

## Базовая линия

Время указано в секундах по данным GitHub Actions.
Общее время — длительность задачи CI без ожидания запуска.

| Этап | 1 | 2 | 3 | 4 | 5 | Медиана |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Set up job | 0 | 1 | 1 | 2 | 2 | 1 |
| Download repository | 2 | 1 | 1 | 5 | 4 | 2 |
| Set up PHP | 3 | 2 | 3 | 3 | 3 | 3 |
| Install dependencies | 5 | 8 | 6 | 5 | 5 | 5 |
| Prepare application | 1 | 0 | 1 | 0 | 0 | 0 |
| Check PHP syntax | 1 | 1 | 1 | 1 | 1 | 1 |
| Check code formatting | 0 | 0 | 0 | 1 | 0 | 0 |
| Run unit tests | 0 | 1 | 1 | 0 | 0 | 0 |
| Run feature tests | 1 | 0 | 0 | 0 | 1 | 0 |
| Build Docker image | 77 | 78 | 79 | 66 | 68 | 77 |
| Post Download repository | 1 | 1 | 0 | 0 | 0 | 0 |
| Complete job | 0 | 0 | 0 | 0 | 0 | 0 |
| Вся задача CI | 94 | 97 | 97 | 97 | 87 | 97 |

Значения этапов округлены интерфейсом GitHub.
Показанное значение 0 не означает отсутствие работы.
Общее время взято отдельно из длительности задачи CI.

Расчёт медианы общего времени:
87, 94, 97, 97, 97 → среднее по положению значение — 97 с.

## Критический путь

Все этапы выполняются последовательно в одной задаче CI,
поэтому входят в критический путь.

Самый длительный этап — сборка Docker-образа:
медиана 77 с при общем времени 97 с.
Он является основным кандидатом на ускорение.

## План оптимизации

Изменения применяются по одному с сохранением предыдущих:

1. Кеширование загрузок Composer.
2. Кеширование слоёв Docker.
3. Параллельное выполнение проверок и сборки.

После каждого изменения выполняются 3–5 успешных запусков.
Их медиана сравнивается с предыдущим вариантом и базовой линией.

## Предварительный вывод

Медиана исходного времени CI — 97 с.
Наибольшую часть времени занимает сборка Docker-образа.
